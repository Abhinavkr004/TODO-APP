# 📝 To-Do List App

A simple and responsive **To-Do List Web App** built using HTML, CSS, and JavaScript.

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Store tasks using Local Storage
- Simple dark-themed UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage
